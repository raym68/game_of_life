## Описание проекта

Программа визуализирует клеточный автомат «Игра Жизнь» Джона Конвея. Пользователь может изменять начальное состояние поля мышью, запускать и останавливать симуляцию, менять скорость и делать одиночные шаги. Поле имеет тороидальную геометрию: противоположные края считаются соседними.

## Функциональные возможности

- Автоматическая генерация начального набора живых клеток.
- Ручное добавление и удаление клеток мышью.
- Запуск и пауза симуляции.
- Пошаговое выполнение в режиме паузы.
- Случайное заполнение и очистка поля.
- Изменение скорости от 1 до 30 поколений в секунду.
- Счётчик живых клеток.
- Подсчёт соседей с переходом через границы тороидального поля.

## Требования к системе

- Python 3.9 или выше.
- Windows, macOS или Linux.
- pygame 2.6.1 (устанавливается из `requirements.txt`).

## Установка и запуск

### 1. Получение файлов проекта

Если проект размещён на GitHub, клонируйте его и перейдите в каталог:

```bash
git clone <ссылка-на-репозиторий>
cd <каталог-репозитория>
```

Или откройте уже имеющуюся папку проекта в терминале.

### 2. Создание и активация виртуального окружения

Создайте окружение в каталоге проекта:

```bash
python -m venv venv
```

Windows (PowerShell):

```powershell
venv\Scripts\Activate.ps1
```

Windows (cmd):

```bat
venv\Scripts\activate.bat
```

macOS / Linux:

```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Запуск программы

```bash
python main.py
```

### Управление

| Клавиша или действие | Результат |
| --- | --- |
| `Space` | Запустить или поставить симуляцию на паузу |
| Левая кнопка мыши | Добавить живые клетки при перемещении указателя |
| Правая кнопка мыши | Стереть клетки при перемещении указателя |
| `R` | Случайно заполнить поле |
| `C` | Очистить поле и поставить симуляцию на паузу |
| `N` | Выполнить одно поколение, пока симуляция на паузе |
| `↑` / `↓` | Увеличить / уменьшить скорость симуляции |

## Структура проекта

```text
.
├── .gitignore
├── README.md
├── main.py
├── requirements.txt
└── src/
    ├── __init__.py
    ├── app.py
    ├── models/
    │   ├── __init__.py
    │   └── game_of_life.py
    └── renderers/
        ├── __init__.py
        └── renderer.py
```

**Назначение файлов:**

- `main.py` — точка входа в программу.
- `src/app.py` — окно Pygame, обработка событий и главный цикл приложения.
- `src/models/game_of_life.py` — модель поля, правила автомата и тороидальный подсчёт соседей.
- `src/renderers/renderer.py` — отрисовка поля, счётчика и подсказки управления.
- `requirements.txt` — точная версия внешней зависимости.

Такое разделение изолирует правила клеточного автомата от графики и обработки ввода, поэтому модель можно развивать независимо от интерфейса.

## Пример использования

1. Запустите `python main.py`.
2. Нарисуйте стартовую конфигурацию левой кнопкой мыши или нажмите `R` для случайного заполнения.
3. Нажмите `Space`, чтобы начать симуляцию.
4. Изменяйте скорость стрелками; для одиночного шага поставьте симуляцию на паузу и нажмите `N`.

## Правила клеточного автомата

Каждая клетка имеет два состояния: живая или мёртвая. Для клетки подсчитываются восемь соседей, включая переход через края поля. В следующем поколении живая клетка сохраняет жизнь при двух или трёх живых соседях; мёртвая клетка оживает при ровно трёх соседях. В остальных случаях клетка становится или остаётся мёртвой.
